## 二、我的技术修订（含 11-14 晨审阅意见的落实）

1. **总需求公式修双重计数**（§四）：原式 G 含"政府支出和转移支付"，但转移支付转化为居民收入后经 c_w 消费才进需求，双重计数。改为 D = c_w(W+T) + c_kΠ + I + G + NX，G 限政府购买，T 单列，文中明写分配环节与购买环节分开。
2. **J 曲线**（§四）：dW/da < 0 改为分段——转型建设期（数据中心/设备安装/电网）W 可升，成熟替代期才转负；并点破这回答"为什么总量数据至今没显危机"。
3. **r(a) 政治参数**（§四末新增段）：r = T/(W+Π) 与政治承受阈值 r̄——把老刘的政治思想与原命题3（自救式越界）**统一进同一套参数语言**：民主 r̄ 低但纠错早，行政 r̄ 高但纠错晚。这是 V4 结构上最重要的一针线。
4. **PCEDG 操作化扩写**（§四末）：PCEDG_t = Y*_t − D*_t + 候选测算数据（产能利用率、劳动收入份额、消费回归系数、消费信贷贡献）+ 明示"研究概念非统计口径"。
5. **§六补财政可持续判据**：转移支付/GDP 与税收能力、自动化利润税基的相对速度，债务轨迹对 IMF 财政空间文献的参照。
6. **军事项加对照组**（§八命题4后）：伊拉克/阿富汗外包化重建的低就业吸收先于无人化存在——比较设计防混淆。
7. **星宇案例挪框**（§九）：独立为"（四）正在发生的制度观察"。
8. **章节顺延**：军事七→八、可证伪八→九、规范九→十、结论十→十一；新增政治章为七。摘要、关键词（+政治可行性；时间不一致）、研究问题（四→五）、结论各补对应笔。
