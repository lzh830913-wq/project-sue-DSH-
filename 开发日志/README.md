## 怎么加一篇（三步）

1. 按 `skills/dev-log/SKILL.md` 的骨架写 `开发日志/YYYY-MM-DD.md`（同日多主题加 `-小标题` 后缀，例：`2026-09-06-step2.md`）。
2. 在**本文件索引表首行**（日期倒序）加一行。
3. `git add` + `commit`（说明带主题）。

> 补记的历史日志：**必须在文首标注「补记」与补记日期**（例：`2026-09-09.md` / `2026-09-10.md` / `2026-09-22.md`）——不许伪装成当天所写。
