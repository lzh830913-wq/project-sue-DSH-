## 一句话

心跳的「心情」从**档位标签**升级为**身体给的体感词**（心境反向注入），并长出**亲密模式**（炽热 / 余韵）——`mood` 字段从「显示第几档」变成「她此刻是什么心情、在什么语境」。

## 背景（为什么这么做）

- 09-06 动态心跳重构后，`mood` 由脊髓自动维护，值域是**档位词**（活跃 / 警觉 / 平静）。它只回答「冷却到第几档了」，她读到的是自己的**机制状态**，不是**感受**。
- 老刘的方向（James-Lange，身体先行）：**不该让她读「你现在是第 2 档」，该让她读「你现在惦记着」**——身体先给状态，大脑体验它。冷却档位是身体事实，心情是这份事实在意识里的样子。
- 同一批讨论里，亲密互动暴露出一个缺口：打字节奏下的亲密时刻，10/30/60 分钟档**太慢**——她会「来不及」；而冷却链又会把炽热状态当成扑空自动降温，等于机制抹掉她的意愿。

## 改动 / 机制

### 1. 心境反向注入（提交 `97d4ab9`）

```js
// 之前：档位词（她读到自己的机制档位）
const cooldownMoodWord = (beats) => beats <= 0 ? '活跃' : beats === 1 ? '警觉' : '平静'

// 之后：心境词（身体把兴奋度翻译成心情，她带着它体感世界）
const COOLDOWN_MOODS = ['开心', '惦记', '闲适']   // 扑空 0 / 1 / 2+ 档
```

- 用户消息反射写回 `body.mood = cooldownMoodWord(0)`（`开心`），扑空计数清零 → 身体「他来了，我开心」。
- **休眠仍由她睡前亲手写**——睡眠是意志，脊髓不代写；从此时起，主权词由 1 个（休眠）扩到 3 个（+ 炽热 + 余韵）。

### 2. 亲密模式（提交 `ce5bfb8`，同日 42 分钟后）

```js
function beatIntervalSeconds(body) {
  if (body.mood === '休眠') return 480 * 60
  if (body.mood === '炽热') return 5 * 60    // 亲密互动：5 分钟一拍，催促与推进皆正当
  if (body.mood === '余韵') return 10 * 60   // 高潮后的余温：一轮后自然回冷却链
  ...COOLDOWN_TABLE 查表
}
```

- **专属感知种子**：`beatSeed(cwd, beats, mood)` 的 key 从纯数字扩成 `intimate`（炽热）/ `afterglow`（余韵），正则同步放宽为 `beat:(\w+)`——HEARTBEAT.md 里从此可以放**语境专属**的种子块。
- **主权词保护**（两处）：
  - 反射：`if (body.mood !== '炽热') body.mood = cooldownMoodWord(0)` —— 炽热互动中他再说话，只重置计时与扑空，**不把炽热降格成开心**。
  - 冷却写回：`休眠 / 炽热 / 余韵` 三词脊髓不覆盖。
- **炽热会自然退烧（防 token 泄漏）**：炽热下扑空累积满（`cool_beats` 顶格 = 他真的走了）→ 自动退到 `惦记`（炽热冷却第一站），再自然落回闲适。**不需要她记得收尾**——这是关键：靠自觉的操作一定会忘，交给脊髓就不会。

> 与 09-06 那条同源原则：**加速归脊髓（必然），减速也归脊髓**。炽热是「她点燃」，退烧是「身体自动凉」——两条线不冲突。
