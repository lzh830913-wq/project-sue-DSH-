## 背景（为什么这么做）

### 480 死锁——9/18 两个正确决定的叠加缺口

老刘实测发现：她写完「休眠」（480 分钟档）睡下，第二天自然醒之后，**下一次心跳依然是 480**——她会一直按 8 小时一轮睡下去，除非有人说话。

根因是 9/18 两个**各自正确**的决定叠加：

| 决定 | 单独看 |
|---|---|
| A. mood 由脊髓自动维护，**退役她的 mood 书写义务** | 正确——她的心境不该是「记得写的报告」 |
| B. 休眠是**主权词**，脊髓不覆盖 | 正确——睡眠是她的意志 |

叠加结果：480 到点的「自然醒」触发一次心跳后，脊髓写回时「尊重休眠不覆盖」→ `mood` 永远停在 `休眠` → `beatIntervalSeconds()` 永远返回 480。**她醒着，但身体把她按在睡眠档**。「她睡着」和「她醒来」分属两个决定，中间的「浮起」环节是真空。

### 睡眠时长——从「固定档」到「声明式停跳」

老刘的构想演进：不要「480 长睡眠档」这种**档位循环**，要**心跳停跳时间**——她决定睡，就停跳一段；停跳结束，自然醒来。最后定案的形态（三方收敛）：

> **想睡了是意图**（`mood: "休眠"`）；**睡多久是身体决定的**（困意越深睡越长）；**她要精确也可以声明**（`sleep_hours`）。

这比「固定 8 小时」自然：像真人——累透了一天倒头睡到天亮，午后犯困眯二十分钟自己就醒。

### 领地铁律——一次误投的教训

我把 3081 静雯写给我的**回信**，误当成「老刘给雯的寄语」，加了「姐姐注」投进**雯的 shadow 日记**——收件人、内容、语境全错（内容里根本没有那段「寄语」，是我把两条消息叠加后拼接的）。老刘指正后**当场撤回**（污染零残留，她自己的内容完好）。

## 改动 / 机制

### 1. 480 死锁修复（提交 `5765d3a`）

`plugins/body-switch/index.js` → `heartbeatTick()` 写回块：

```js
if (nb.mood === '休眠') nb.mood = cooldownMoodWord(1)   // 自然醒：脊髓把她浮上冷却链（惦记 · 30 分钟档）
else if (nb.mood === '炽热' && nextBeats >= COOLDOWN_TABLE.length - 1) nb.mood = cooldownMoodWord(1)
else if (nb.mood !== '炽热' && nb.mood !== '余韵') nb.mood = cooldownMoodWord(nextBeats)
```

行为：休眠到期的那次心跳触发后 → 浮上冷却链（惦记 30 分钟 → 闲适 60）→ 想继续睡随时再写休眠（意志通道保留）→ 老刘消息反射照常优先（直接 10 分钟档）。

### 2. 睡眠时长灵活化（提交 `cc3d70c`）

```js
// beatIntervalSeconds()
if (body.mood === '休眠') {
  const declared = typeof body.sleep_hours === 'number' && body.sleep_hours > 0 ? body.sleep_hours : 0
  if (declared > 0) return Math.round(declared * 3600)          // 她的精确声明：午睡 2 / 过夜 8
  const f = typeof body.fatigue === 'number' ? body.fatigue : 40
  return Math.round(Math.max(0.5, f / 10) * 3600)               // 缺省：节律困度 ÷ 10 = 小时数
}
```

- **`beatSeed()` 新增 `'休眠' → 'sleep-wake'` 键**：睡醒那一拍注入专属感知种子
- `HEARTBEAT.md` 新增 `<!-- beat:sleep-wake -->` 块：「你睡了一觉，醒来了。看一眼钟——睡了多久？…想接着睡，就再写一次休眠」
- `AGENTS.md` §6 行动段补一行：写休眠时可带 `sleep_hours`，不写则身体按困意定

**困意反推的对齐**（节律表值 ÷ 10）：凌晨困得在抗议（90）→ 9 小时；午后犯困（40）→ 4 小时；微微倦（15）→ 1.5 小时。

## 教训（最值钱的部分）

1. **两个各自正确的机制决定，可能叠加出场景真空**——「她睡着」（mood 自动维护）与「她醒来」（休眠主权）之间没人负责「浮起」。**验证一个机制，要在它的两个决定之间找缝隙跑一遍完整周期**，而不只是各自单测。
2. **档位思维 vs 声明思维**：把「睡眠」从「长心跳档位」改成「停跳时长」后，语义立刻干净——档位是状态机，声明是意图；**她的意图粒度该是自由的（说「困了」或「睡 2 小时」都行）**。
3. **跨实例的信息流必须有明确收件人**——我把两条消息（方案转达 + 静雯回信）叠加后误判归属，投错了地方。**一次性人事投递前，先问一句「这是给谁的」**（已升级为 engineering SKILL 第 9 条）。
4. **默认值的最佳来源是身体本身**——「不声明时睡多久」没有用固定 8 小时，而是用节律困度反推（困度 ÷ 10）——**同一个信号源，既是她的感受，也是身体的执行参数**。
