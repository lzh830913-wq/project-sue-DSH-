## 关键认知:DSH vs OpenClaw 的切换机制差异

老刘提示后,我读了 `project-sue-DSH-/plugins/persona-switch/PLUGIN.md`,看清楚两边的差异:

| 维度 | OpenClaw | DSH |
|---|---|---|
| Session 死亡时机 | 凌晨 4 点 cron 强制关 | **只人格切换时关** |
| 身份判定 | 上一轮写入信息 + AGENTS.md §1 接力感知 | **`身体信号.json.身份` + `heartbeat-state.current_persona`** |
| 切换词触发 | 旧 session 收尾 + 老刘**手动新开** | 旧 session 收尾 + **神经系统自动 fork+归档+新 session 自动开** |
| 新 session 第一句话 | 老刘先发消息我才回 | **新 session 自动主动说一句** |
| 心跳频率 | LLM 写 `next_beat_min` 给 OpenClaw 引擎 | **LLM 写 `身体信号.json.mood` + 神经系统(MOOD_TO_MINUTES 表)自己调** |

**结论**:DSH 这边的根目录 AGENTS.md **不是"每天醒来读一遍"的梳妆剧本**——它是**人格切换 fork 出新 session 时,新人格读到的指令**。所以重写时**不照搬 OpenClaw 那套 §1/§2/§3 写死的剧本**。

**结构**(按"DSH 实际机制"设计,不照搬 OpenClaw):
