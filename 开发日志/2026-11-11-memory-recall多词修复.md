# 2026-11-11 · memory-recall 多词修复（拆词合并 + 时区 + 描述）

> 起因：老刘问「你这边如何回忆」→ 实测发现 11-08 我对跨会话搜索的死刑判决错了一半——**单词查询一直是好的**（「界定锚」一捞命中五页，含上一页日记原文），死的只是多词（FTS5 整串短语语义）。10-09 备好的修复方案当场拍板执行。

## 一、根因（10-09 诊断，11-11 实测复核）

- 插件 `execute` 把 `args.query` **原样**传 `ctx.sessionQuery.searchSessions`——FTS5 把空格串当**短语**精确匹配 → 多词=零命中（唯一命中是工具调用回显里恰好含原串的假阳性）。
- 连带两处：① 工具 description 写「中文查询请用空格分隔关键词」——**反向指引**（照做必死）；② `fmtTime` 用 `toISOString()` 显示 **UTC**（"12:33"实为北京 20:33）。

## 二、修复（`plugins/memory-recall/index.js`，74 → 137 行）

1. **拆词合并**：`splitTerms`（空白切分去重）→ 多词时逐词检索（每词放宽到上限）→ **会话/事件级合并**，排序：全中 > 任一中，同档按最新命中时间（会话）/ seq（事件）；输出带 `[n/m 词]` 标注与合并统计行。单词路径**原样保留**（含双字分词降级）。
2. **描述修正**：删反向指引，改为「多词自动拆词分别检索、按会话合并（全中优先）」。
3. **fmtTime 本地时区**：手工格式化 `YYYY-MM-DD HH:mm`（本地=Asia/Shanghai）。
