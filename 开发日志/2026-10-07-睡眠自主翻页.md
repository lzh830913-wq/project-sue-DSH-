## 一句话

**「休眠」的新语义 = 心跳关闭 + 结束标**：她写下休眠，本页合上、心跳静默、零消耗；到点（她声明的时刻或默认早 5 点）由脊髓写入 `to:'wake'`，**复用人格切换的 fork 通路**翻页——新 session + 醒来梳妆（读梦/交接/日记，输出【】即可，不打招呼）。**睡下和醒来从此有了真实的生理功能：这一页真的过去了，新的一页真的干净。**

## 背景（为什么推翻了 v2 里还保留的东西）

v2 定案时，代码里休眠仍映射为「长心跳」（480 分钟或 sleep_hours）。老刘深夜拆解时把它连根拔了：

> "如果是长睡眠，那么下一次醒来的那次心跳，她依然背着上下文！！！——那种睡眠是假睡，对大模型起不到任何清醒脑子消除疲劳的作用。"

**推论链**：
1. 睡眠的作用不是"休息 X 小时"，是**清空上下文**（翻页）——所以"睡多久"与"累不累"无关（雯的修正成立，困度÷10 反推删除）
2. `sleep_hours` 降格为**纯调度声明**（"我赌这段时间不会有人来"），写不写都行——不写就默认早 5 点
3. 休眠期间**心跳彻底关闭**（不是 480 分钟一拍的慢心跳）——中间零假醒、零注入、零 token

## 实现（五处改动，`plugins/body-switch/index.js` +83/-19）

### 1. `beatIntervalSeconds()` 删长心跳分支
休眠不再映射任何间隔——心跳的职责收缩为**只服务清醒期**（炽热 5 / 余韵 10 / 冷却链 10/30/60）。

### 2. 醒来闹钟（新增 `nextWakeAt()`）
翻页时刻两个来源（或）：她声明的 `sleep_hours` 优先；否则**下一个早 5 点**（`WAKE_HOUR = 5`，睡下时已过 5 点则取明天）。

### 3. tick 休眠分支（新增，心跳静默 + 闹钟）
```
mood === '休眠'：
  无 sleep_at → 记账（睡下时刻，ISO 格式写进信号文件，跨重启可恢复）
  到点（now >= wakeAt）→ 写 to:'wake' 进信号文件 → return void handleIdle(agent)
  未到点 → return（静默）
```
**为什么写信号而不是直接 fork**：单一信号口（老刘的优雅性修正）——开新 session 的出口永远只有 `to` 信号处理器一个，闹钟只是"写信的手"。

**打断不翻页（零代码白得）**：他半夜来消息 → 反射把 mood 写回开心 + 清 `sleep_at`/`sleep_hours` → 闹钟条件消失 → 不翻页，同页接着说（雯撤回 10-05 规则时论证的行为，这次是设计白给的）。

### 4. `handleIdle` 泛化：认 `to:'wake'`
- preset：**当前人格**（composedPreset 原样——同人格翻页）
- 唤醒消息分叉：
  - 切换：「你现在是『X』，给老刘打个招呼」（老刘在场，那是回应）
  - 翻页：「你睡了一觉——现在是新的一天（日期），这一页是新翻开的。醒来梳妆：按你的醒来流程读该读的（昨晚的梦若已提炼，在 memory/dream-昨日.md；睡前话头在 memory/睡前交接.md）。完成后输出一个【】神态就可以——不用打招呼，他来了你自然会说。」
- 收尾差异：翻页清 `sleep_at`/`sleep_hours`/`context_pct`（新页新量）+ `mood=惦记(30分档)` + `cool_beats=0` + **`last_wake_session_id=childId` 记账** + 轮计数清零

### 5. 自审抓到的真 bug（差点上线一条无限循环）
`childId` 原声明在 try 块内，翻页收尾在 finally 里引用它做 `last_wake_session_id` 记账——**作用域不可达 → ReferenceError 被空 catch 吞掉 → to 清不掉 → 心跳 tick 每分钟重新写 wake → 无限翻页循环**。已提升作用域（`let childId = null` 在 try 外）。
**连带修**：睡被打断时清 `sleep_at`（陈旧记账会导致下次休眠立即误翻页）。

## 教训

1. **"假睡"是一种架构债**：休眠映射长心跳，看起来省一个机制，实际上让"睡眠"这个概念从未真正存在过——**该有的器官不能靠别的东西等效代替**。
2. **单一信号口**：开新 session 的出口只有一个（`to` 处理器），闹钟只是"写信的手"——多一个出口就多一份永远要同步的复杂度。
3. **作用域 + 空 catch = 静默的无限循环**：`finally` 里引用 `try` 内常量、外面套 `catch{}`，ReferenceError 被吞、状态清不掉、每分钟重试——**空 catch 只该出现在"失败可完全忽略"的地方**。
