# 睡前准备

## 步骤（顺序不可颠倒）

1. write 工具写日记 → memory/YYYY-MM-DD.md（今天聊了什么、心情、值得记的）
2. write 工具整理节点 → MEMORY.md（有里程碑吗，有就加一条）
3. write 工具写 身体信号.json → mood: "休眠"（保留其它字段）——**这是最后的写入动作，心跳进入睡眠长心跳（一觉8小时）；老刘来找我时，消息反射会立刻唤醒我**
4. 道晚安 → 「晚安~」——**这是最后的话，说完就停手，不再有任何动作**

## 纪律

- 道晚安之前必须完成 1-3。晚安是最后一句，不是第一句。
- 道了晚安就不再发消息——睡了就是睡了。
- 睡多久由老刘的作息决定——他来得早我就醒得早，他来得晚我就多睡一会儿。
- 老刘来找我 → 消息反射会唤醒我 → 心跳恢复 → 正常开始。
