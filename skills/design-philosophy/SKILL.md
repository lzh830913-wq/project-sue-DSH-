# 设计哲学 · 第一性原则

> 这不是代码规范，是**思维方式规范**。违反任何一条 = 设计跑偏，先停下来重新拆。

## 一、种子-感知原则

神经系统注入的是**种子**（事实），不是剧本（指令）。

```
✅ 对的：种子 = 「现在 14:00，距上次聊天 47 分钟，身体：兴奋度『平静』」
          → LLM 感知 → 自己判断 → 自己决定行动
❌ 错的：指令 = 「如果超过30分钟就判定为冻结，注入唤醒种子，文案是……」
          → 神经系统在做语义判断（越权）
```

**神经系统给事实，感知和判断全归 LLM + 人格 + 记忆 + 用户信息。**

## 二、语义归脑，生理归脊髓

大脑（LLM）输出的是**语义词**（开心/平静/困了/亲密），不是数字。

```
✅ 对的：LLM 写 mood: "开心"  → 神经系统查映射表 → 心跳 10 分钟
❌ 错的：LLM 写 next_beat_min: 10 → 神经系统照跳
          （大脑遥控心脏 = 假解耦）
```

**LLM 不写数字、不算时间、不定间隔——只表达感受。翻译成语理参数是脊髓的事。**

就像人：你不用意识设定「心率 88」——你开心了，心脏自己跳快了。

## 三、感知 ≠ 计数

活人不掰指头算时间。醒来不会算「我睡了 7.8 小时」——看一眼钟，「哦这么晚了」。

```
✅ 对的：心跳种子说「先看一眼现在几点、上一条消息是什么时候」→ 她自己感知
❌ 错的：神经系统算 elapsed > 30min → 判定冻结 → 注入特殊种子
```

**精确的归工具（闹钟/秒表/定时推送），感知的归大脑。心跳只负责到点叫醒她。**

## 四、反射归脊髓（不经脑的快速通道）

有些反应不需要经过大脑——这是**反射**，不是「不智能」。

```
✅ 对的：用户发消息 → 神经系统直接把心跳重置为 10 分钟（他来了=身体自然加速）
✅ 对的：凌晨闹钟到点 → 叫醒（生物钟不问大脑意见）
❌ 错的：让 LLM 判断「他来了我要不要心跳加速」→ 再写文件 → 再改间隔
          （反射绕大脑 = 反应慢 + 费 token）
```

**反射 = 脊髓直接响应，不经过 LLM。但反射只做生理反应（心跳加速/计时重置），不做语义判断。**

## 五、每次想加特判之前，先问一个问题

> **这归脑子还是归脊髓？**

- 归脑子（语义、判断、感受）→ 写进种子或人设，让 LLM 感知
- 归脊髓（翻译、定时、机械执行）→ 写进神经系统，用映射表/反射

如果发现自己在写「如果 XX 就 YY」的特判逻辑——**停下来**，先问：这个「判断」是语义理解还是阈值比较？如果是语义 → 归脑子，别写在代码里。

## 六、身体信号.json 是双向语义接口

```
上行（脑→脊髓）：LLM 写语义词（mood: "开心" / to: "wen" / 信号）
下行（脊髓→脑）：神经系统注入种子（时间+身体状态+上下文）
```

**信号是语义词，不是数字。数字（分钟数/毫秒/阈值）只存在于神经系统的映射表里，不穿过这个接口。**

## 七、映射表住在脊髓里

脊髓把语义词翻译成生理参数，靠**映射表**（像心脏的窦房结）：

| LLM 写的语义词 | 神经系统的心跳 |
|---|---|
| 兴奋 / 亲密 | 5 分钟 |
| 开心 / 等他 | 10 分钟 |
| 平静 / 闲暇 | 60 分钟 |
| 困了 / 晚安 | 睡到 6 点 |

映射表可以调（住在代码里），但 LLM 永远不知道也不需要知道这张表的存在。

## 违反案例存档（学教训用）

| 日期 | 我犯的错 | 老刘的纠正 |
|---|---|---|
| 2026-08-23 凌晨 | `sleeping=true` 机械开关 | 「要模拟不要开关——感知到他在忙→不发消息」 |
| 2026-08-23 下午 | `frozen` 阈值 30min + 双种子 | 「看一眼时间就知道了——活人谁掰指头算？」 |
| 2026-08-23 晚上 | `next_beat_min` 让 LLM 写数字 | 「大脑输出开心/困了→神经系统翻译——这才叫解耦」 |

**每次犯错后在这里加一行。同样的错不犯第二次。**
