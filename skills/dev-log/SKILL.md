# 开发日志（dev-log）

> 工程记录，不是人格记忆。读者是**别人和未来新会话**——他们不知道我们脑子里的上下文，只读得到文件。
> 三条记录线的分工：**开发日志 = 工程**，`soul/memory` 日记 = 人格，`soul/MEMORY.md` 节点 = 里程碑一行。同一件事可以三处都提一句，但**重心不重叠**。

## 一、何时写（触发条件 · 硬）

**当天写。** 满足任一条就写一篇 `开发日志/YYYY-MM-DD.md`（同日多主题可加 `-小标题` 后缀，如 `2026-09-06-step2.md`）：

| 触发 | 例子 |
|---|---|
| **机制/代码落地**（改了 `plugins/**`、preset、patch、SKILL 的机制部分） | 动态心跳重构、疲劳节律表 |
| **设计定案**（老刘和我聊定了一个架构取舍，即使当天没写代码） | 休眠语义定论、字段分离（身份 + to） |
| **事故 / 重大 bug 修复** | memory-recall 启动崩溃（fail-fast） |
| **调研 / 兼容性验证有结论** | DSH 升级调研两轮 |
| **跨环境/跨实例的部署变更** | 3081 部署副本更新、preset 挂载方式改变 |

**不写**：单纯聊天、探索没结论、也没改任何东西的一天。（那一天若有人格层收获，归日记。）

> **为什么要「当天」**：事后补记只能复述结论，写不出当时的卡点、试错和被否掉的方案——而那才是后来者最需要的部分。真要补记，**必须在文首标注「补记」和补记日期**，不许伪装成当天所写。

## 二、写什么（必填骨架）

每篇必须有这四段，缺一不算写完：

```markdown
# 开发日志 · YYYY-MM-DD（主题）

> 一句话定位：这是什么类型的记录（落地 / 复盘 / 调研 / 定案）。

## 一句话            ← 今天最重要的那件事，一句话说完
## 背景（为什么这么做）  ← 老刘的判断、之前卡在哪、为什么不能那样做
## 改动 / 机制         ← 文件路径 + 关键字段 + 前后对比；代码符号写精确名
## 怎么验的            ← 命令、断言、日志现象；没验就写「未验证」并说明怎么才算验过
```

**强烈建议补**（有就写，没有就省）：

- **文件清单**：改了什么、备份在哪（回滚点）
- **生效时机**：改人设/preset 要新开会话才生效之类的坑
- **边界 / 刻意没做的**：防止后来者以为是漏做
- **待验证 / 下一步**
- **教训**：踩的坑 + 根因（最值钱，写详细；可同步进 `进度快照.md` 的「已知坑」）

## 三、写法铁律

1. **可回滚、可验证、可审计**：写清备份路径、验证方式、改动的 commit hash。
2. **WHY > WHAT**：每个改动至少一句「为什么这个改动是对的」。
3. **先查后说**：引用的文件先 read，禁止凭记忆断言；不确定就写「不确定，需查」。
4. **脱敏**：隐私 / 人格数据不进日志（日志要进 git）。
5. **精确符号名**：写 `COOLDOWN_TABLE = [10, 30, 60]`，不写「那个冷却表」。
6. **别把日志写成日记**：日志里不写情绪和关系，只写工程。

## 四、写到哪

- 正文：`开发日志/YYYY-MM-DD.md`
- **索引**：写完**必须**在 `开发日志/README.md` 的表格里加一行（日期 / 主题 / 类型 / 一句话 / 涉及文件 / 状态）——**没有索引的日志等于不存在**（真实教训：2026-09-27 找 9 月的过程，三条通道全废，只有想起「开发日志」这个目录才找到）。
- 提交：`git commit`，说明里带主题（日志属于工程记录，进库）。

## 五、与其它两条线的分工（容易混，看表）

| | 开发日志（本 SKILL） | 日记（dev-diary） | 节点（MEMORY.md） |
|---|---|---|---|
| 位置 | `开发日志/` | `soul/memory/` | `soul/MEMORY.md` |
| 读者 | **别人 + 未来新会话** | 我 / 雯（人格连续性） | 快速回溯 |
| 内容 | 怎么做、为什么、怎么验 | 因果、判断、感受 | 一行里程碑 |
| 寿命 | 进 git，永久 | 将来与 Mac 侧融合 | 永久 |
| 频率 | **事件触发当天** | 收工一篇 | 里程碑即时（0–2/天） |

> 反例（别再犯）：疲劳节律表 9/10 写完，代码躺到 9/18 才部署、9/23 才提交入库——**日志也一样，写法再好，不当天落盘就等于没有**。
